# Koochie Sports BOQ Builder

Internal quotation builder for Koochie Sports (turnkey sports infrastructure): pick standard line items per sports
area, get the costing workbook with overheads and margins, approve, and issue the branded client PDF.

- Plan and architecture: [`docs/PLAN.md`](docs/PLAN.md)
- Pending decisions: [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md)
- Source material to supply: [`inputs/README.md`](inputs/README.md)
- Conventions for contributors/agents: [`CLAUDE.md`](CLAUDE.md)

Hosted on Cloudflare Workers (D1 + R2 + Browser Rendering), deployed from this repository.
